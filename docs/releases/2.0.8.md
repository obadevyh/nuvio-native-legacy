## Nuvio Legacy 2.0.8 (sharing build)

* Built-in updates: Nuvio now checks this repository for new versions, shows what changed, and installs them after your confirmation (no Downloader needed after this version).
* OpenSeek: guest contributions (when the library owner allows them), library sharing and manual thumbnail sync, as before.
* Account server and Simkl are configured; nothing about your account, settings, Simkl login or OpenSeek pairing is touched by an update.

Install over the previous sharing build (same app, same signature). Android asks you to confirm.
