# Nuvio Legacy 2.0.10 (OpenSeek-integrated sharing build)

Same code as 2.0.9 with one change: **the in-app update checker now reads `obadevyh/nuvio-native-legacy`** (this repository).

* Same package name (`space.nuvio.nativelegacy.sharing`) and the same signing certificate as 2.0.9, so it installs over the existing app and keeps your account, profiles, settings, Simkl login, OpenSeek address and pairing.
* **Installs of 2.0.9 and older check the previous repository and will not see this update.** Install this APK once by hand; later updates arrive in the app.
* Experimental, unofficial build. See the README.
