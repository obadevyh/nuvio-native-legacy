## Nuvio Legacy 2.0.13 (sharing build)

Brings this build up to date with the latest Nuvio Legacy. OpenSeek, contributor mode and in-app updates work as before.

New from Nuvio Legacy:
* A format row under the title in the player (resolution, HDR, Dolby) with a selectable style.
* An opt-in tunneled playback setting on Android TV.
* Performance settings now default to automatic, with steadier automatic effects and upscaling on 4K panels.
* Live TV: fixed long stream requests, the Automatic HLS quality and the channel limit.
* Subtitles: provider labels in the menu, cached session subtitles and better sync labels.
* Artwork: fixed a reload loop, smaller artwork loads when memory is tight, and posters refresh when you change the metadata language.
* Fixes for Search backdrops, episode menus on scaled screens, AIOStreams instances, Simkl anime episodes and Library sync.

Your account, settings, Simkl login and OpenSeek pairing stay as they are.

In-app updates now come from github.com/obadevyh/nuvio-native-legacy (the previous repository is gone).
